# Kakao Carousel Preview

카카오톡 캐러셀 피드형 메시지를 발송 전 미리보기 할 수 있는 정적 웹페이지입니다.

## 파일 구성

```txt
index.html
style.css
script.js
```

## GitHub Pages 업로드 방법

1. GitHub 저장소에서 `Add file` → `Upload files` 클릭
2. 아래 3개 파일을 모두 업로드
   - `index.html`
   - `style.css`
   - `script.js`
3. 같은 이름 파일이 있으면 덮어쓰기 방식으로 commit 됩니다.
4. `Commit changes` 클릭
5. Pages 반영까지 1~3분 기다린 뒤 새로고침합니다.

## 강력 새로고침

수정했는데 예전 화면이 계속 보이면 브라우저 캐시일 수 있습니다.

- Mac: `Cmd + Shift + R`
- Windows: `Ctrl + F5`

## 주요 기능

- 기본 카드 2개
- 최대 카드 6개
- 카드 6개 초과 시 안내창
- 이미지 업로드
- 타이틀 20자 제한
- 본문 180자 제한
- 본문 줄바꿈 2회까지 허용
- 본문 줄바꿈 3회 이상 시 흔들림 및 빨간색 경고
- CTA 최대 2개
- CTA 2개 초과 시 CTA 영역 하단 경고
- CTA 클릭 시 입력 링크 새 탭 이동
- 브랜드명 선택: DEFENDER, Range Rover, Discovery
- 한번에 보기 모드
- 하단 dot 캐러셀 이동
- 모바일 반응형 지원
